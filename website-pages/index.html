About the author

Dr. Mudassar Hussain Hashmi researches computational solid mechanics, fracture mechanics, fractal analysis and probabilistic analysis at Universiti Teknologi Malaysia (UTM). His published work models how fatigue cracks grow through metallic materials, combining finite-element analysis with fractal and probabilistic methods.

Alongside this research, he writes publisher-style reference books for Python, Matplotlib and PySide6 — each one built chapter by chapter, with every code example tested before publication.
