Personal profile

Dr. Mudassar Hussain Hashmi

Mechanical engineer, fatigue and fracture mechanics researcher, and author of the Python for Engineers and Scientists series.

Islamabad, Pakistan mhhashmi48@gmail.com +92 342 563 7291

I am a highly motivated, detail-oriented researcher with a strong background in mechanical engineering, hands-on programming experience, and a proven research profile built alongside professional research work. My published work models how fatigue cracks grow through metallic materials, combining finite-element analysis with fractal and probabilistic methods.

Alongside this research, I write publisher-style Python reference books for engineers and scientists — for Python itself, Matplotlib and PySide6 — each one built chapter by chapter, with every code example tested before publication.
